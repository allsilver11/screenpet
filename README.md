# ScreenPet 🐾

바탕화면 위를 돌아다니는 동물 친구. 작업표시줄과 창 윗라인 위를 걷고, 잡아서 던지면 창 위에 착지해요.

## 설치 (Windows)
1. GitHub → **Actions** → 최신 `build` 실행 → **Artifacts**의 `screenpet-windows` 다운로드
   (태그 `v*`를 푸시하면 **Releases**에도 올라감)
2. `.exe`(NSIS) 또는 `.msi` 실행
3. "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행** (코드 서명 안 된 앱이라 그래요)

## 설치 (macOS 11+, Apple Silicon·Intel 공용)
1. Artifacts의 `screenpet-macos`(또는 Releases)에서 `.dmg`를 받아 열고 **ScreenPet**을 **응용 프로그램**으로 끌어다 놓기
2. 처음 열 때: 응용 프로그램에서 **우클릭 → 열기 → 열기** (서명 안 된 앱이라 그냥 더블클릭하면 막혀요).
   그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**
3. Dock 아이콘은 없고, 메뉴 막대 오른쪽의 동물 아이콘이 트레이 메뉴예요
4. "로컬 네트워크의 기기를 찾도록 허용" 창이 뜨면 허용 (친구 화면용 — 거절해도 나머지는 정상)

## 사용법
> 고양이는 새침해요 — 클릭하면 대부분 무시하거나 투덜대요(배고플 땐 애교쟁이). 애교를 원하면 트레이에서 강아지로!

- 트레이 아이콘(발바닥) 메뉴 — 동물을 우클릭해도 같은 메뉴: 동물 선택 / 밥 주기 / 성장 멈추기 / 처음부터 다시 키우기 / 숨기기·보이기 / 종료
- 클릭: 애교 (고양이는 새침해서 자주 무시) · 자는 동물은 세 번 빠르게 눌러야 깸
- 배고파하면(시무룩 + 🍙) 클릭해서 🍪 🍚 (좋아하는 것) 중 골라 먹이기 — 먹을수록 조금씩 자람
- 드래그해서 던지기: 창 윗라인이나 작업표시줄에 착지
- 🎮 조작 모드 (메뉴 체크): ← → 걷기 · Shift 달리기 · Space(또는 ↑) 점프 · ↓ 앉기 (창 위에서 ↓ 두 번 = 뛰어내리기) · 고양이·곰·개구리는 화면 끝 벽 쪽 + ↑로 기어오르기, ↓로 미끄러져 내려오기 · 꿀벌·유령은 방향키로 위아래 좌우. 친구 화면에 놀러 간 내 동물도 조작돼요. Esc나 메뉴로 끝 (키 없이 3분이면 저절로 끝). **조작 모드 중엔 방향키가 다른 창에도 입력돼요** (키를 가로채지 않고 읽기만 해요). macOS는 "입력 모니터링" 권한이 필요할 수 있어요 (시스템 설정 → 개인정보 보호 → 입력 모니터링)
- 🕐 최근 한 시간: 트레이 `🐾 내 펫 ▸ 🕐 최근 한 시간` — 펫이 지난 한 시간 동안 집에서 놀기 / 하우스 / 어느 친구네에 얼마나 있었는지, 무엇을 몇 번 먹었는지. 메모리에만 있고 저장·전송하지 않아요
- 🎲 사다리타기: 트레이 `친구랑 놀기 ▸ 사다리타기…`에서 친구를 고르고(방장 포함 10명) 결과 칸을 적어 초대 → 모두의 난수로 정해지는 사다리를 각자 화면에서 펫들이 내려가요. 끝나면 지문 이모지 4개가 모두 같은지 확인 (같으면 같은 판을 본 것. 고친 앱의 방장이 결과를 먼저 보고 다시 여는 것까지 막지는 못해요)
- 친구 화면: 같은 네트워크의 ScreenPet끼리 트레이 `친구랑 놀기 ▸`에서 친구 신청 → 양쪽 창에 뜬 그림 6개가 같은지 확인하고 둘 다 "똑같아요"를 누르면 친구. 그 뒤로는 동물이 스스로 화면 끝을 넘어 친구 화면에 놀러 가고 돌아와요 (`집에 와`로 바로 불러올 수 있음)
- 친구와 연결되는 길: 같은 네트워크의 친구와는 직접 연결돼요. 다른 네트워크의 친구와는 중계 서버 `pet.danni.day`를 거쳐 연결돼요. 메시지는 양쪽 앱 사이에서 암호화되므로 중계 서버는 내용을 읽을 수 없어요 (서버는 누구와 누구를 이어 줄지 알아야 해서 설치별 공개키·id·친구 키 목록·친구 코드는 저장해요). 중계를 끄려면 설정 폴더의 `relay_url.txt` 첫 줄에 `off`라고 적어요

## 개발
```bash
cargo test                       # 코어 로직 (리눅스/맥/윈도우 어디서나)
cargo run -p screenpet-net --example ladder_bot -- --dir /tmp/bot1 --name 봇1   # 사다리타기 시험용 봇 (같은 PC에서 여러 개, WSL이면 --relay + 친구 코드, 콘솔 `i` = 봇이 방장, `a <코드>` = 봇끼리 친구)
cd tools && python -m pytest     # 스프라이트 도구
npm install && npm run tauri dev # 앱 실행 (Windows)
```
- 코어 로직: `crates/screenpet-core` · 앱: `src-tauri` · 화면: `ui`
- 동물 추가/교체: [docs/sprites.md](docs/sprites.md)

## 수동 테스트 체크리스트 (Windows)
- [ ] 실행하면 동물이 화면 위쪽에서 떨어져 작업표시줄 위에 착지
- [ ] 걷다가 화면 끝에서 뒤돌기
- [ ] 동물을 창 윗라인 위로 던지면 그 위에 착지
- [ ] 창 위를 걷다 모서리에서 뒤돌거나 폴짝 뛰어내림 (반반)
- [ ] 다른 창이 윗라인 일부를 가리면 그 앞에서 멈칫하고 뒤돌기
- [ ] 서 있는 자리에 다른 창을 끌어다 덮으면 놀라며 떨어짐
- [ ] 동물이 탄 창을 드래그해 옮기면 같이 이동
- [ ] 동물이 탄 창을 최소화/닫으면 떨어짐
- [ ] 휙 던지면 화면 벽에서 튕김
- [ ] 클릭하면 하트 + 점프 (자는 중 클릭은 아래 "졸린 클릭" 참고)
- [ ] 트레이에서 동물 바꾸기 → 앱 재시작 후에도 유지
- [ ] 숨기기/보이기, 종료
- [ ] 작업표시줄을 위/왼쪽으로 옮겨도 바닥이 맞음
- [ ] 듀얼 모니터에서 다른 화면으로 던지기
- [ ] 디스플레이 배율 125% / 150%에서 위치가 어긋나지 않음
- [ ] 최대화된 창(윗라인이 화면 맨 위)에는 올라가지 않음
- [ ] 동물 주변 투명한 여백을 클릭하면 아래 창이 아니라 펫 창이 클릭됨 (v1 알려진 제한)
- [ ] 걷기·뛰기·데구르르 구르기가 섞여 나옴 (대부분 움직이고, 잠은 가끔 짧게)
- [ ] 뛰다가 창 모서리에서 멀리 점프, 구르다가 모서리에서 굴러 떨어짐
- [ ] 구를 때 공처럼 말려 진행 방향으로 회전 (왼쪽으로 갈 땐 반대로)
- [ ] 멈춰 있을 때 가끔 앞모습 애교 (앉아서 바라보기·손 흔들기·고개 갸웃·배 보여주기·기지개·하트)
- [ ] 애교 중에는 왼쪽을 보고 있었어도 얼굴이 정면 (반전 안 됨)
- [ ] 클릭하면 점프+하트 / 하트 뿌뿌 / 손 흔들기 / 갸웃 중 하나
- [ ] 그림 가장자리가 매끈함 (계단 없음)
- [ ] 클릭 없이 동물 위에서 마우스를 빠르게 흔들면 꼬물꼬물 웃음 + "hehe!", 멈추면 잠시 뒤 원래대로
- [ ] 자는 동물을 간질이면 실눈 뜨고 💢, 멈추면 다시 잠, 5초 넘게 간질이면 "hmph!" 하고 깸
- [ ] 고양이가 가끔(간질일 때도 가끔) 등을 휘고 꼬리를 펑 부풀리며 "hiss!"
- [ ] 강아지가 가끔(간질일 때도 가끔) 혀를 내밀고 꼬리를 흔듦
- [ ] 가끔(20~40초) 머리 위에 작은 말풍선 (고양이 meow!/nya~ 등), 클릭할 때도 가끔
- [ ] 고양이 `arch`/강아지 `wag` 도중 트레이에서 동물을 바꿔도 멈추거나 사라지지 않음
- [ ] 처음 실행하면 아주 작은 아기 고양이 (설정이 없을 때 기본 동물은 고양이)
- [ ] 한참(약 22분) 지나면 배고파함: 시무룩 + 🍙 생각 풍선 + "hungry..." 말풍선
- [ ] 배고플 때 클릭 → 머리 위에 🍪 🍚 (좋아하는 것) 버튼 → 고르면 냠냠
- [ ] 배부를 때 트레이 밥 주기 → "full~" 하고 갸웃
- [ ] 여러 번 먹이면 "I grew up!!" 만세하며 한 단계 커짐 (트레이에 단계 표시 없음)
- [ ] 트레이 "성장 멈추기" 켜면 먹어도 안 큼, "처음부터 다시 키우기" → 아기로
- [ ] 동물마다 성장 따로 저장, 앱 재시작 후에도 유지
- [ ] 예전에 비버를 키웠으면 곰으로 바뀌고 성장 단계가 그대로 이어짐
- [ ] 아기 모습이 단계마다 확실히 다름 (아기는 머리가 크고 통통)
- [ ] 곰은 child부터 다른 동물보다 크고, 토끼는 조금 작음
- [ ] 고양이는 새침: 클릭하면 대부분 무시("...")하거나 흥! 하고 고개 돌림, 배고플 땐 애교가 많아짐
- [ ] 졸린 클릭: 자는 동물을 한 번 누르면 짜증내고 다시 잠, 2초 안에 세 번 누르면 하품(기지개)하며 깸
- [ ] 고양이·곰은 가끔 화면 벽을 무작위 높이까지 기어올랐다 미끄러져 내려옴, 내려오다 창 윗라인에 착지
- [ ] 고양이·곰을 창 옆면에 던지면 붙어서 타고 올라가 창 위에 올라섬
- [ ] 벽 타기(뒷모습)는 왼쪽으로 가도 좌우 반전 안 됨
- [ ] 동물을 우클릭하면 트레이와 같은 메뉴가 커서 위치에 뜸 (웹뷰 기본 메뉴는 안 뜸)
- [ ] 음식 고르기 버튼을 누를 때 동물이 잡히지 않음
- [ ] 메뉴 "하우스" → 오른쪽 아래 구석(작업표시줄 바로 위)에 집이 나타나고 동물이 집으로 달려가 문간에 앉음 (창 위에 있으면 뛰어내리고, 다른 모니터에 있으면 건너옴, 느린 아기도 끝까지 달려 들어가고, 길이 막혀 있으면 펄쩍 뛰어 들어감). 메뉴 글자가 "하우스에서 나오기"로 바뀜
- [ ] 집으로 가는 중엔 클릭해도 반응 없이 계속 감, 끌어다 놓으면 떨어진 뒤 다시 감
- [ ] 하우스 안: 대개 앞모습으로 앉아 있고 가끔 잠, 집을 누르면 손 흔듦, 말풍선은 집 위에 뜸
- [ ] 하우스 안에서 배고플 때 집을 누르면 집 위에 음식 고르기 → 문간에서 냠냠, 크면 문간 동물도 커짐
- [ ] "하우스에서 나오기" → 문 앞에서 왼쪽으로 걸어 나오고 집이 사라짐
- [ ] 하우스 안에서 앱을 껐다 켜면 하우스 안에서 시작, 하우스 안에서 동물을 바꾸면 새 동물도 하우스 안

### 조작 모드
- [ ] 메뉴 "🎮 조작 모드" 체크 → 머리 위 🎮, 안내 말풍선, 동물이 저절로 돌아다니지 않음 (먹이·직접 주기·클릭·하우스는 그대로)
- [ ] ← → 걷기, Shift 달리기, 놓으면 그 방향을 보고 멈춤 / Space·↑ 점프로 창 윗면에 올라섬, 공중에서 ← →로 조금 방향 틀기
- [ ] ↓ 앉기, 창 위에서 ↓ 두 번 빠르게 → 뛰어내림 / 고양이: 화면 끝 벽 쪽 + ↑ 기어오르기, 놓으면 매달림, ↓ 미끄러져 내려옴
- [ ] 꿀벌·유령: 방향키로 위아래 좌우, 놓으면 그 자리에 떠 있음
- [ ] 방향키가 앞에 있는 다른 창(메모장 등)에도 그대로 입력됨 (가로채지 않음)
- [ ] Esc 또는 메뉴로 끝 → 🎮 사라지고 체크 풀림, 다시 저절로 돌아다님 / 키 없이 3분 → 저절로 끝, 체크 풀림
- [ ] 친구 화면에 가 있는 내 동물: 내 키로 움직임, 친구 쪽 동물 머리 위에 🎮, 친구가 연결된 끝으로 몰면 걸어 나감. 친구는 여전히 끌고 클릭 가능, 집 그리움·"집에 와"·돌려보내기가 우선
- [ ] 예전 판 친구에게 놀러 간 동물: 조작은 안 되지만 연결이 끊기지 않고 평소처럼 놂

### 친구 화면 (PC 두 대, 같은 네트워크)
- [ ] 처음 실행 때 Windows 방화벽 허용 창이 뜸 (허용 안 하면 친구 찾기만 안 되고 나머지는 정상)
- [ ] 두 PC 모두 트레이 `친구랑 놀기 ▸`에 상대 이름 "— 친구 신청"이 몇 초 안에 보이고, 한쪽을 끄면 몇 초 뒤 사라짐
- [ ] 친구 신청 → 양쪽에 작은 "친구 맺기" 창이 뜨고 이모지 6개가 똑같음. 둘 다 "똑같아요, 친구 맺기" → "친구가 되었어요!" 후 창이 닫힘
- [ ] "친구 맺기" 창이 주 모니터 가운데에 뜸 (모니터가 여러 개여도)
- [ ] 두 사람이 거의 동시에 서로 친구 신청하면 각자 자기 신청을 지키고 상대 신청은 거절됨 → 한 사람이 다시 신청하면 친구가 됨
- [ ] 친구의 이름은 연결될 때(●) 상대가 알려 준 이름으로만 바뀜 (같은 네트워크의 다른 PC가 같은 id로 다른 이름을 알려도 친구 이름은 그대로)
- [ ] 한쪽이 "달라요 / 취소"를 누르거나 20초 동안 확인하지 않으면 양쪽 모두 취소됨, 상대가 꺼져 있으면 10초 뒤 "연결하지 못했어요"
- [ ] 친구 메뉴에 ● (연결됨) / ○ (끊김) 표시, 첫 친구는 "오른쪽에", 두 번째 친구는 "왼쪽에"
- [ ] 두 앱을 모두 다시 시작해도 다시 묻지 않고 자동으로 연결됨 (●)
- [ ] 내 동물이 친구가 연결된 끝으로 걷다가 가끔 걸어 나가 사라지고, 친구 화면 반대편 끝에서 "🏠 <내 이름>" 이름표를 달고 걸어 들어옴

### 🕐 최근 한 시간
- [ ] `🐾 내 펫 ▸ 🕐 최근 한 시간` → "지금: 🎈 집에서 놀기 (방금)", 1분 뒤 "(1분째)", 막대 오른쪽 끝이 계속 자람
