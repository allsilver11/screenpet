🐾 ScreenPet 도움말

펫은 트레이 아이콘이나 펫을 우클릭하면 나오는 메뉴로 다뤄요.

🐱 동물마다 달라요

  • 캐릭터 ▸에서 동물을 바꿔요. 동물마다 성격과 특기가 달라요.
  • 🐱 고양이: 새침해서 클릭해도 시큰둥, 가끔 등을 세우거나 "흥". 🐶 강아지: 꼬리 살랑. 🐰 토끼: 걷다가 반쯤은 깡총깡총.
  • 🐱🐻🐸 고양이·곰·개구리는 벽이나 창 옆면을 타고 올라가요. 🐸 개구리는 폴짝 뛰어다니고 가끔 창 위로 크게 점프해요.
  • 🐝 꿀벌: 화면을 둥실둥실 날아다녀요. 너무 괴롭히면(연타·간질이기·흔들기) 화면에 침을 콕! 👻 유령: 둥실 떠다니고 간질이면 스르륵 투명해져요.
  • 🎃 호박: 통통 튀고, 누를 때마다 눈빛이 다른 모양으로 번쩍. 🦌 루돌프: 빨간 코가 반짝. 🎅 산타: 가끔 썰매를 타요.
  • 🦆 오리: 뒤뚱뒤뚱. 🦒 기린: 가끔 목을 두 배로 쭉 늘려요. 🦖 공룡: 불을 뿜고 으르렁, 쿵쾅 발을 구르면 근처 펫들이 휘청!

🍚 밥 주고 키우기

  • 밥이나 좋아하는 음식을 먹으면 숨은 성장 점수가 쌓이고, 다 차면 한 단계 자라요.
  • 간식 🍪·물 💧은 배불러도 아무 때나 먹일 수 있고, 성장에는 영향이 없어요.
  • 배고프면 펫이 알려줘요. 펫을 누르면 밥/좋아하는 음식 고르기가 떠요.
  • 직접 주기: 마우스 끝에 음식이 붙어요. 펫 입에 갖다 대면 받아먹어요 (우클릭·Esc로 취소). 자동 주기: 그릇이 놓이고 펫이 걸어가 먹어요.
  • 아기 → 유치원 → 어린이 → 청소년 → 어른. 지금 단계는 메뉴의 🌱 줄에서 봐요.
  • 성장은 동물마다 따로예요. 캐릭터를 바꿨다 돌아오면 그 동물이 자라던 단계부터 이어서 키워요.
  • 성장 멈추기로 지금 모습 그대로 두고, 처음부터 다시 키우기로 아기부터 다시 키울 수 있어요.

🖱️ 같이 놀기

  • 마우스를 펫 위에 올려 간질여 보세요. 클릭하면 애교를 부려요. 자는 펫은 세 번 콕콕 누르면 깨요.
  • 펫을 잡아서 끌고 던질 수 있어요. 화면 바닥뿐 아니라 창 위, 창 안에도 내려놔 보세요. 창을 움직이면 같이 따라와요.
  • 펫은 창 위를 걷고, 모니터가 여러 대면 건너다녀요. 가끔 위를 올려다보기도 해요.
  • 같은 화면에 펫이 둘 이상이면 서로 인사하고 쫓고 쫓기며 놀아요.
  • 🎮 조작 모드: ←→ 걷기 (Shift 달리기), Space/↑ 점프, ↓ 앉기, 벽 쪽+↑ 벽 타기, Esc 끝내기. 꿀벌·유령은 방향키로 날아요. 친구 화면에 간 내 펫도 조종돼요. (방향키는 다른 창에도 같이 들어가요)

💞 친구 맺기

  • 같은 와이파이면 친구랑 놀기에 상대가 보여요. 누르면 친구 신청!
  • 멀리 있으면 내 친구 코드 보기로 코드(예: ABCD-1234)를 알려주고, 상대는 친구 코드 입력…에 넣어요. 새 코드로 코드를 바꿀 수 있어요.
  • 양쪽 화면에 같은 이모지 6개가 뜨면 둘 다 확인을 눌러야 친구가 돼요.
  • 친구 이름 앞 ●는 연결됨, ○는 꺼짐. 연결 끊기로 지우고, "다시 친구 맺기 필요"가 뜨면 다시 맺어요. 친구는 50명까지.
  • 내 이름: 친구 화면에 간 내 펫 위에 뜰 이름을 정해요. 친구마다 별명도 붙일 수 있어요 (내 화면에서만 보여요).

🚀 친구 화면으로 놀러 가기

  • 친구마다 왼쪽에 / 오른쪽에를 정하면, 펫이 그쪽 화면 끝으로 걸어가 친구 화면으로 넘어가요.
  • 그쪽 벽으로 펫을 세게 던지면 듀얼 모니터처럼 친구 화면으로 날아가요.
  • 놀러 보내기: 손 흔들고 뿅! 바로 보내요. 편지 들려 보내기 💌: 펫이 편지를 들고 가요. 친구가 봉투를 누르면 10초간 말풍선으로 보여요.
  • 펫 데리고 오기: 온라인인 친구의 펫을 내 화면으로 불러와요 (그 펫이 쉬는 중이면 거절해요).
  • 놀러 간 펫은 3~6분 놀다 집이 그리워 돌아와요. 다른 친구 쪽 끝에 닿으면 그 친구에게 또 놀러 가기도 해요. 바로 부르려면 집에 와!
  • 연결이 끊기면 펫은 바로 집으로 돌아와요.

🏡 친구 펫이 놀러 오면

  • 놀러 온 펫 위엔 주인 이름이 처음 10초 동안 떠요. 누르면 다시 보여요.
  • 클릭하면 애교를 부리거나, "catch me!" 하며 마우스를 피해 도망가요.
  • 우클릭하면 주인에게 돌려보내기나 다른 친구에게 보내기를 할 수 있어요. 한 화면에 손님은 10마리까지.

🏠 잠깐 조용히

  • 성가실 땐 하우스로 펫을 집에 들여보내요. 집도 펫과 함께 자라고, 꿀벌은 벌집, 호박·유령은 귀신의 집, 루돌프·산타는 눈 쌓인 벽돌집에 살아요.
  • 집은 마우스로 끌어서 옮길 수 있어요. 집에 있을 때 밥을 주면 문 앞에 그릇이 놓여요.
  • 숨기기 / 보이기로 화면에서 잠깐 감출 수도 있어요.
