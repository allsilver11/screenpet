# 🧳 포트키 (2026-11-23 요청)

사용자: "물건 꺼내기로 물건 꺼내면, 그중 하나를 해리/헤르미온느/볼드모트가 순간이동하는 포트키로 쓰게 해줘.
친구 화면으로도 포트키 들고 갈 수 있게 해줘."

## 정한 것

- 누가: 마법사 (해리·헤르미온느·볼드모트 — pet.json에 `portkey: true`). 내 펫이든 친구 손님이든.
- 언제: 화면에 놓인 **모든 물건이 포트키가 될 수 있음** (사용자 2026-11-23: "모든 물건이 다 포트키가 되도록 — 똥도, 거대 돌/거대 똥, 쓰레기들, 다"):
  물건 꺼내기로 나온 것, 💩 똥, 🪨 거대 돌·거대 똥, 쓰레기, 📌 앱 아이콘 장난감 모두. 바닥·창 위에 놓여 있으면 됨 (들려 있거나 날아가는 중인 것은 아님).
  가끔 (마법사마다 쿨다운 몇 분) "Portkey!" 하고 달려가 손을 댐 — 거대한 것은 잡지 않고 손만 댐.
  같은 물건 = 같은 종류 + 같은 그림 (똥은 똥끼리, 거대 돌은 거대 돌끼리, 📌 장난감은 같은 앱 아이콘끼리).
- **짝 물건이 있어야 함** (사용자 2026-11-23: "내 화면에서도 신문지를 포트키 삼아, 신문지가 여러 개라면 다른 신문지로 뿅 나타나게.
  같은 물건이 내 화면이든 친구 화면이든 아무 데도 없으면 텔레포트 안 하게"): 포트키는 늘 **같은 물건 (kind + look — 같은 그림) 두 개 사이**를 잇는 문.
  - 마법사는 같은 물건이 내 화면에 하나 더 있거나, (새 버전) 친구 화면에 있을 수 있을 때만 포트키를 고름. 내 화면에 짝이 없고 친구 쪽도 없으면 아예 안 함.
- 잡으면: 마법사만 빙글 돌며 작아지고 반짝 사라짐 (✨ magic 효과). **포트키 물건은 늘 제자리에 남음** (들고 가지 않음). 나타나는 곳:
  1. **내 화면의 짝 물건** — 같은 물건이 내 화면에 또 있으면 (여럿이면 아무거나) 그 물건 자리에서 반짝 빙글 펑 하고 나타나 옆에 털썩.
  2. **친구 화면의 짝 물건** — 친구가 연결돼 있고 새 버전이면 (내 화면에 짝이 있어도 반쯤의 확률로 친구 쪽을 먼저) 친구 앱에 물어봄:
     친구 화면 바닥에 같은 물건이 있으면 그 자리에서 펑. 없거나 친구가 바쁘거나 몇 초 넘게 답이 없으면 → 내 화면에 짝이 있으면 1번, 없으면 그 자리에서
     다시 나타남 ("huh?" — 텔레포트 안 됨).
  - 돌아올 때는 평소처럼 (걸어서/집에 와). 손님 마법사가 포트키를 잡으면 손님이 있는 화면 (내 화면)의 짝 물건으로만, 또는 주인·다음 친구 쪽으로 같은 규칙.
- 같은 포트키를 마법사 여럿이 동시에 잡으면 같이 감 (같은 곳에 나타남).
- 하우스·집중·숨기기·조작 모드·자리 비움 중에는 안 함. 친구가 바쁘면(하우스·집중) 친구 화면 대신 내 화면 안으로.

## 친구 통신

- `Visit`에 새 칸 `portkey: {kind, look}` — 받는 쪽은 바닥의 같은 물건을 찾아 그 자리에 나타나게 하고, 없으면 바쁠 때처럼 돌려보냄 (보낸 쪽은 내 화면의 짝으로, 그것도 없으면 제자리).
- 새 버전끼리만: `PROTOCOL_VERSION` 올리고 `peer_version`으로 보내는 쪽이 고름 (옛 친구에겐 친구 쪽 포트키를 안 씀 — 내 화면의 짝 물건만).
- 받는 쪽은 kind·look을 아는 값인지 확인 (모르면 거절), 나타날 자리는 받는 쪽 물건 자리 (화면 밖·창 속이 아님).

## 테스트

- 코어: 고르기 규칙 (똥·거대한 것·장난감 포함 모든 놓인 물건·짝 물건이 있을 때만·쿨다운·바쁠 때 안 함), 잡기 → 사라짐 → 짝 물건 자리에 나타남, 짝이 없으면 안 함, 같이 잡기, 물건은 제자리.
- 통신: `portkey` 칸 읽기·옛 형식 호환·이상한 값, 같은 물건 없으면 거절.
- 앱: 소스 검사 (친구 쪽 포트키는 물건을 싣지 않음, 거절되면 내 화면의 짝 물건으로 (없으면 제자리), 옛 친구 게이트).
