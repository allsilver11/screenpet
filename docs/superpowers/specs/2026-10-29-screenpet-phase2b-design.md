# ScreenPet 2B — 밥 주기·성장 설계

- 작성일: 2026-10-29
- 선행: 2A (`2026-10-29-screenpet-phase2a-design.md`, 브랜치 feat/phase2a)
- 사용자 요청 원문 요약 (2026-10-28): 배고프다 하면 밥 3종 중 골라 주기 → 숨겨진 체력 stat 증가 → 레벨별 stat이 차면 한 단계 성장.
  baby → kinder → child → teenager → adult, 아주 작은 새끼로 시작해 점점 커짐. 레벨 리셋·레벨 고정(고정 중에도 배고파하고 먹지만 stat·성장 없음).
  레벨 고정 시 다른 단계 모습 미리보기 불가. v1 크기 = teenager, baby는 훨씬 작게.

## 1. 돌보기 수치 (core `care.rs`)

| 항목 | 값 |
|---|---|
| 포만감 `fullness` | 0.0~1.0, 앱이 켜져 있는 동안 30분에 1.0 감소 (꺼져 있는 동안은 멈춤) |
| 배고픔 | `fullness < 0.25` (밥 먹고 약 22분 뒤) |
| 배부름 | `fullness > 0.9`면 먹기 거절 ("full~") |
| 체력 `stamina` | 숨김. 먹을 때 증가, 단계 필요량을 채우면 다음 단계로 (남은 값은 0으로) |

음식 3종 (모든 동물 공통 2개 + 동물별 좋아하는 것 1개):

| 음식 | 체력 | 포만감 | 비고 |
|---|---|---|---|
| 간식 🍪 `snack` | +3 | +0.4 | |
| 밥 🍚 `meal` | +10 | 1.0으로 채움 | |
| 좋아하는 것 `favorite` | +15 | +0.7 | 고양이 🐟, 강아지 🦴, 토끼 🥕, 곰 🍯 꿀. 먹고 나면 하트 애교 |

단계:

| 단계 | 크기 배율 | 다음 단계까지 체력 |
|---|---|---|
| baby | 0.45 | 60 |
| kinder | 0.60 | 100 |
| child | 0.78 | 150 |
| teenager | 1.00 (v1 크기) | 220 |
| adult | 1.15 | — (최종) |

밥만 먹이면 baby→kinder 6끼(앱 켜둔 시간 약 2.5시간), adult까지 53끼(약 20시간).

- **레벨 고정**: 배고픔·먹기·애니메이션은 그대로, 체력·성장만 없음.
- **처음부터 다시 키우기**: baby, 체력 0, 포만감 1.0으로.
- 동물마다 따로 키운다 (고양이 진행이 강아지에 영향 없음).
- 저장: `config.json`에 동물별 `care` 기록. 변화가 있을 때 + 60초마다.
- 기존 사용자(설정에 care 없음)는 baby부터 시작.

## 2. 행동 (brain)

- **배고플 때**: 쉬기로 넘어갈 때 50%로 `hungry` 동작(앞모습, 시무룩하게 앉아 배 쓰다듬기, 머리 위 생각 풍선에 🍙), 3~5초.
  평소 대사 대신 15~25초마다 배고픔 말풍선("hungry...", "food?").
- **클릭**: 배고플 때 짧게 클릭하면 애교 대신 **음식 고르기**가 뜬다 (아래 §4). 배고프지 않으면 2A 클릭 반응 그대로.
- **먹기**: `eat` 동작(앞모습, 그릇에서 냠냠) 2.5초 → 좋아하는 음식이면 `heart` 애교 2초, 아니면 바로 움직임.
- **거절** (배부름): 말풍선 "full~" + `tilt` 애교 2초.
- **성장**: 먹기가 끝나면 `level_up` 동작(앞모습, 반짝이며 만세) 2초 + 말풍선 "yay!", 그 순간 몸 크기가 다음 단계로.
- 공중·드래그 중에는 먹거나 성장 연출을 시작하지 않는다 (먹이 명령은 무시하지 않고 착지 후 처리하지 않아도 됨 — 공중이면 거절 없이 무시).

## 3. 단계별 그림

- 동작 목록에 `hungry`, `eat`, `level_up` 추가 → 필수 21개 (앞모습 3개 모두).
- 단계마다 비율이 다른 시트: `ui/pets/<id>/sheet_<stage>.png` 5장 (+ 호환용 `sheet.png` = teenager).
  - baby: 머리 크게(×1.25), 몸 작게, 다리 짧게 / kinder ×1.15 / child ×1.07 / teenager 기준 / adult 머리 ×0.93, 몸·다리 길게.
  - 작은 단계는 화면에서 줄어드므로 외곽선을 상대적으로 두껍게 (표시 크기에서 약 2px 이상 유지).
- 웹뷰는 현재 단계 시트만 읽는다. 단계 시트가 없으면(`pack_sheet`로 넣은 AI 그림) `sheet.png`로 대체.
- **미리보기 금지**: 트레이·말풍선 어디에도 단계 이름이나 다음 모습을 보여주지 않는다.

## 4. 화면 (Tauri)

- **펫 창 크기**: 너비 `128 × max(1, 배율)`, 높이 `36 + 128 × 배율` (논리 px). 동물은 아래 가운데, 위 36px는 말풍선·음식 고르기 자리. 성장하면 창 크기를 바꾼다 (발 위치 고정).
- **음식 고르기**: 위 36px 띠에 버튼 3개(🍪 🍚 좋아하는 것). 6초 동안 안 고르면 사라짐. 고르면 `feed` 명령.
- **트레이 메뉴**: `밥 주기 ▸ 간식 / 밥 / 좋아하는 것(동물별 이름)`, `성장 멈추기`(체크), `처음부터 다시 키우기 ▸ 정말 처음부터 키울까요? (새끼로 돌아가요)`.
  트레이 밥 주기는 배고프지 않아도 누를 수 있다 (배부르면 거절 연출).
- 말풍선 대사 추가: `hungry` ["hungry...", "food?"], `full` ["full~"], `level_up` ["yay!", "♪♪"] (모든 동물 공통).

## 5. 테스트

- care: 포만감 감소·배고픔 경계, 음식별 효과, 배부름 거절, 단계 상승·필요량·adult 상한, 고정 시 체력 불변, 리셋, 직렬화 왕복·기존 설정 호환.
- brain: 배고플 때 hungry 동작 비율, 배고픔 말풍선이 평소 대사를 대신함, 배고플 때 클릭 → 음식 요청, eat → (좋아하는 것이면 heart) → 이동, refuse, level_up, 공중 무시.
- 그림: 21동작 × 5단계 × 4종 생성·잘림 없음, 단계가 클수록 머리/몸 비율 감소.
- 수동: README 체크리스트에 밥·성장 항목.

## 6. 사용자 피드백 반영 (2026-10-29)

- **동물별 크기**: pet.json `stage_size` (단계 이름 → 배율, 없으면 1.0). 곰 1, 1, 1.1, 1.2, 1.3 / 토끼 0.85 전 단계 / 고양이·강아지 1.0. 화면 크기 = `Stage::scale × size_mult`.
- **고양이 성격 (`"personality": "aloof"`, 기본 friendly)**:
  - 애교 확률 10% (배고프면 60%). 쉬기에서 애교(55%) 대신 이 확률을 쓴다.
  - 깨어 있을 때 클릭: 애교 확률이면 평소 클릭 반응, 아니면 반반으로 **무시**(하던 일 계속, 절반은 "..." 말풍선) 또는 **흥**(`huff` 앞모습 1.5초 + "hmph!"). 배고프면 음식 고르기가 먼저(그대로).
- **잠**: 잠들 확률 12%, 10~20초. 자는 동물을 한 번 누르면 뒤척이고(`annoyed` 1.5초) 다시 잔다. 2초 안에 세 번 누르면 기지개(`stretch` 2.5초)를 켜며 깬다. 5초 간질이기로 깨우는 건 그대로.
- **차분한 전환** ("걷다가 갑자기 애교, 갑자기 동그래져서 굴러다녀"):
  - 활동 묶음: 걷기·달리기 / 구르기 / 앞모습(애교·흥·간질·배고픔·먹기·성장) / 특별 동작. 묶음이 바뀔 때는 사이에 옆모습 앉기 0.6~1.5초.
  - 이동·착지가 끝나면 항상 먼저 잠깐 앉고, 그 뒤에 애교/잠/이동을 정한다. 애교가 아니면 1.5~3초(절반은 두리번) 더 앉아 있다가 잠/이동을 정한다.
  - 이동 관성: 다음 이동은 50% 직전 방식 그대로(실제로 시작한 이동만 기억). 애교 뒤 다음 이동은 70% 걷기.
  - 애교 시간 3~5초.
- 10분 시뮬레이션 (friendly, 특별 동작 없음): 움직임 58%, 앞모습 14%, 잠 7%.

## 7. 벽 타기 (고양이·곰)

- **능력**: pet.json에 선택 동작 `climb`·`slide`(뒷모습, 좌우 반전 없음)가 둘 다 있으면 벽을 탄다 (`PetConfig::can_climb`, `PetManifest::can_climb`). 없는 동물(강아지·토끼)은 그대로.
- **화면 타기 (저절로)**: 새 이동을 고를 때(차분한 전환 규칙 그대로 — 다른 활동 뒤면 먼저 잠깐 앉는다) 6% 확률로 대신 화면을 기어오른다. 디딤판 위에 서 있을 때만.
  - 목표 높이: 발밑 모니터 작업 영역 기준 `bottom − u × (bottom − (top + 몸 크기))`, u ∈ [0.25, 1.0]. 이미 그보다 높은 곳(높은 창 위)에 서 있으면 평소처럼 이동한다.
  - 기어오르기: 디딤판 없이(화면 유리 위) x 고정, 70 px/s(크기 128 기준, 크기에 비례). 창이 가려지거나 사라져도 상관없다. 목표에 닿으면 0.4초 매달렸다가 미끄러진다.
  - 미끄러지기: 중력 없이 250 px/s로 똑바로 내려오며, 지나치는 창 윗면이나 바닥에 내려선다(착지 판정·화면 밖 복구는 낙하와 같음).
  - 오르거나 미끄러지는 중엔 공중처럼 다룬다: 잡으면 바로 들리고(놓으면 떨어짐), 간질이기·호버 반응·수다 없음.
- **창 옆면 타기 (던졌을 때)**: |vx| > 50으로 던져진 동물의 몸 앞쪽 끝이 바깥에서 창 옆면을 넘으면, 발이 창 윗면 + 몸 1/4보다 아래이고 창 아래끝보다 위이며 그 지점이 앞쪽 창에 가려지지 않았을 때 옆면에 달라붙는다 (여럿이면 가장 가까운 옆면).
  - 창을 따라 움직이며(창 바깥쪽에 붙음) 90 px/s로 기어오르고, 꼭대기에 닿으면 옆면 바로 안쪽(몸 절반 + 2 px) 창 윗면에 올라선다(착지).
  - 창이 사라지거나 붙은 지점이 앞쪽 창에 가려지면 떨어진다. 그림은 `climb`(뒷모습).
- 벽 타지 않는 동물의 10분 시뮬레이션 수치는 그대로. 벽 타는 동물 10분 시뮬레이션: 패닉 없음, 늘 화면 안, climb/slide가 나온다.
