# 🖍️ 짱구 추가 (사용자 요청 2026-11-21, 0.7.2)

재미용 개인 앱. 꼬마 치비이되 짱구 특유의 모습: 아주 굵은 까만 눈썹, 감자처럼 아래가 넓은 머리 (볼 통통), 까만 머리, 빨간 반팔 티셔츠, 노란 반바지, 하얀 양말·운동화. 뒷모습은 머리가 팔을 가림. 5단계 동글 그림, 말은 짧은 영어 (짱구 말투 느낌), 선물 없음. 미리보기로 5단계 확인 후 보고.

특기 (새 그림 몇 개):
- 🍑 엉덩이 춤: 엉덩이를 내밀고 좌우로 씰룩씰룩 (반바지 입은 채 — 노출 없음), "buri buri~" 
- 🦸 액션가면 흉내: 허리에 손 얹고 "Action beam!" 손 뻗기 (빔 반짝)
- 🍪 초코비: 좋아하는 음식 (작은 과자 상자 아이콘), 가끔 꺼내 먹음
- 💕 예쁜 누나에게 작업: 헤르미온느가 같은 화면에 있으면 쪼르르 가서 "Hey pretty~" 하고 쑥스러운 표정 (헤르미온느는 웃거나 무시)
- 😴 뒹굴뒹굴: 바닥에 누워 뒹굴뒹굴 / 엎드려 다리 까딱
- 🐶 흰둥이: 가끔 작은 하얀 솜뭉치 강아지가 옆에 나타나 졸졸 따라다니다 사라짐 (작은 오버레이 그림)
