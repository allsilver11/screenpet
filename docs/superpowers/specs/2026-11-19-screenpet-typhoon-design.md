# 🌀 여름 태풍 (Weather::Typhoon) — 설계

사용자 요청: 정신없고 재밌게. 회오리가 자주 빨아들이고, 친구 화면으로도 자주 날려 보냄. 안전장치는 네트워크 예산(던지기·방문 규칙)을 넘지 않고 아무것도 잃어버리지 않을 만큼만.

## 언제 오나
- 📅 달력: 7~9월, 날짜로 정해진 날(대략 이틀에 하루)에 하루 1~2번, 한 번에 5~10분 (`weather::typhoons`). 소나기·푸른 잎·낙엽보다 먼저.
- 🌦️ 날씨 종류 ▸ 🌀 태풍 (`WeatherSource::Typhoon`, id `typhoon`): 직접 고른 날씨처럼 계속 옴.
- ☀️ 실제 날씨: 중계 서버는 WMO 코드만 줌 (바람 세기 없음). 뇌우(95·96·99)가 7~9월이면 태풍, 그 밖의 달엔 예전처럼 비.
- 네트워크: 날씨 이름은 친구에게 가지 않음 (쓸어 보내는 더미 `flurry:<kind>`만 감 — 태풍은 쌓이지 않으니 보내지 않음). PROTOCOL_VERSION 그대로.

## 그림 (ui/weather.js)
- 굵게 비스듬한 빗줄기 + 옆으로 날아가는 푸른 잎·부스러기 (알갱이 예산 그대로 ≤ 80).
- 장면에 `wind`(−1.6…1.6, 부호 = 방향)를 실어 돌풍마다 비·잎이 더 눕고 빨라짐.
- 장면에 `tornado: [x, y, vx]` (논리 px, 바닥 중심): 회색 깔때기를 그려 vx로 사이를 이어 그림.
- 더미는 쌓이지 않고 빨리 날아감 (녹는 속도 큼) + 돌풍 때 남은 더미가 옆으로 흩날림.

## 돌풍 (core typhoon::Gusts)
- 3~7초마다 1~2.5초, 세기 0.3~1. 방향은 대개 한쪽 (가끔 바뀜).
- 동물 (`Pet::feel_gust`): 버팀("hold on!" + 덜덜) / 데굴 (Tumble, "whoa!") / 날아감 (던지지 않은 낙하, "wheee!"). 나는 동물은 떠밀림.
  자는 동물은 덜덜만. 하우스 안·들림·창 안·떠나는 길·먹는 중·조작 모드·집중·자리 비움은 그대로.
- 물건: 바닥에 놓인 작은 것(거대한 것 빼고)이 옆으로 휙 (`Object::blow` — 던진 게 아니라 친구 화면으로는 안 넘어감).

## 회오리 (core typhoon::Tornado, Storm)
- 태풍 동안 몇 초 쉬고 나타나 40~90초 동안 한 모니터 바닥을 이리저리 돌아다님 (빠르기·방향이 자주 바뀜).
- 바닥 근처 PULL_RADIUS 안의 동물·물건을 빨아들임 (한 번에 MAX_RIDERS까지): 깔때기를 따라 빙글빙글 올라가다 (1.4~2.6초) 휙 내던짐.
- 내던질 때 친구 쪽 끝이 있으면 CROSS_CHANCE(75%)로 그 끝까지 닿는 포물선 (던진 비행 → 기존 넘어가기 길):
  - 물건: `Object::launch` → 끝을 넘으면 `toss_away` (친구별 TossBudget, 예산이 없으면 끝이 닫혀 벽에 튕김).
  - 내 동물: 던진 비행 → `fling_out` → `own_exited` (바쁜 친구는 되돌아옴, 방문 기록·AwayVisit 그대로). 동물 넘기기는 PET_CROSS_GAP(8초)에 한 번까지 — 물건은 친구별 던지기 예산에만 걸림.
  - 손님: 집 쪽 끝으로만 (guest_left → 주인에게 돌아감). 집 쪽이 위/아래면 그냥 이 화면에서 데굴.
  - 끝까지 못 닿는 자리(최대 속도로도)면 이 화면에 내던짐.
- 회오리에 든 동물은 `Dragged` 그림으로 매달려 돎. 사용자가 잡으면 바로 놓아줌. 앱이 자리를 알려 주지 않으면 0.3초 뒤 저절로 떨어짐 (태풍이 끝나도 잃어버리지 않음).
- 방금 내던진 것은 잠깐(RECATCH_SECS) 다시 빨아들이지 않음.

## 그대로인 것
- 🧹 쓰레기 다 치우기·한 시간마다 더미 치우기는 PileField 그대로.
- 창은 overlay::show_quietly / hide_quietly / set_click_through만 (새 창 없음 — 깔때기는 날씨 덮개 창에 그림).
