# 💩 똥피하기 — 설계

화면 위에서 똥이 떨어지고, 방향키로 내 펫을 움직여 피한다. 한 번 맞으면 끝, 점수 = 바닥까지 떨어진 똥 수.
친구들끼리 최고 기록 랭킹을 본다.

## 결정

- **별도 게임 창이 아니라 바탕화면 위에서**: 날씨처럼 펫이 있는 모니터의 작업 영역을 덮는 투명 창(`dodge`)에 똥을 그린다.
  펫은 진짜 내 펫 — 작업표시줄·창 윗면 위를 그대로 걷고 뛴다.
- **키는 게임 창이 받는다**: 조작 모드는 키를 전역으로 읽기만 해서 다른 앱에도 들어간다. 게임 동안 방향키가 메모장 등에
  들어가면 안 되므로 게임 창이 포커스를 갖고 keydown/keyup을 `dodge_keys`로 보낸다. 게임 창은 클릭도 받는다
  (살짝 어두운 배경 = 게임 중). 창을 떠나면(blur) 키를 다 놓은 것으로 본다. Esc·닫기·Alt+F4면 원래대로.
- **움직임은 조작 모드 그대로** (`brain_control.rs`): 걷기·Shift 달리기·Space 점프·창 위에 오르기. 판이 시작되면
  `set_control(true)`, 끝나면 끈다. 🎮 조작 모드 메뉴는 게임 창이 열린 동안 켜지지 않는다 (열 때 켜져 있었으면 끈다).
- **판 밖으로 나가지 않는다**: 게임 창이 열린 동안 화면 끝 나가기(친구에게 놀러 가기)를 막는다. 다른 모니터로 넘어가면 그 자리에서 끝.
- **어려움**: 속도 240 → 950 논리 px/s (1초마다 +9), 간격 0.8 → 0.14초. 폭 1600 논리 px 기준이라 넓은 화면엔 더 자주.
  30%는 펫 머리 위를 노린다 (가만히 서 있으면 맞는다). 처음 1초는 떨어지지 않는다.
- **맞음 판정**: 그림보다 조금 작게 (똥 반지름 60%, 펫 반 폭 75%, 높이 = 몸 0.8배). 한 틱에 지나간 길 전체로 본다
  (빠르거나 틱이 길어도 뚫고 지나가지 않게). 맞으면 펫이 "ew!" 하고 납작.
- **랭킹**: 최고 기록만. 내 기록은 `config.dodge_best`, 친구 기록은 `Friend.dodge_best` (받은 적 없으면 없음 — 랭킹에 안 보임).
  친구 링크의 "부탁"(`Ping.ask`)에 `dodge:<점수>`로 싣는다 — **프로토콜 변경 없음**. 예전 판은 모르는 부탁을 무시하므로
  연결이 끊기지 않는다. 연결될 때(`Connected`)와 새 기록일 때 보낸다. 점수는 친구가 보낸 그대로 믿는다 (검증할 길이 없다, 친구끼리).
  부탁 예산(2개 + 2초에 1개)을 이름 바꾸기와 같이 쓴다 — 드물게 보내므로 충분하다.

## 구조

- 코어 `crates/screenpet-core/src/dodge.rs` — 판(`Dodge`: 떨어뜨리기·떨어지기·맞음·점수), `PetBox`, 부탁 형식, `ranking`. dt로만 돈다.
- 앱 `src-tauri/src/dodge.rs` — 창, 커맨드 `dodge_state`·`dodge_keys`·`dodge_start`·`dodge_close`, 게임 루프의 `steer`(키 → 펫)·`tick`(판 → 창, 기록).
- `network.rs` — 점수 부탁 받기·보내기. `config.rs` — 기록 필드.
- UI `ui/dodge.html`·`dodge.js` — 똥 그림(`objects/poop.png`, 픽셀이면 `objects_pixel/`), 점수, 시작·결과 카드.
