# ScreenPet 2A — 활발한 행동 + 카와이 디자인 설계

- 작성일: 2026-10-29
- 상태: 검토 대기
- 선행: `2026-10-28-desktop-pets-design.md` (v1, main e421ed7)
- 후속: 2B 돌보기·성장 (별도 설계)

## 1. 목표

v1 실기 테스트에서 "계속 자기만 한다"는 피드백이 나왔다 (10분 시뮬레이션: 잠 38%, 걷기 34%).
2A는 동물을 **활발하고 귀엽게** 만든다.

- 활발도 조정, 뛰기·데구르르 구르기 이동 추가, 창에서 더 자주 뛰어내리기
- 앞모습 애교 동작 6종 (앉아서 바라보기, 손 흔들기, 고개 갸웃, 배 보여주기, 기지개, 하트 뿌뿌)
- 클릭 반응을 애교 랜덤으로 확장
- 그림을 "말랑 카와이" 스타일 128px로 전면 교체 (임시 그림 폐기)
- 2B 성장을 위한 크기 배율 구조 (이번엔 1.0만 사용)

### 범위 밖

- 배고픔·밥·stat·성장 단계 (2B)
- macOS, 여러 마리 동시 표시

## 2. 행동 규칙

### 2.1 수치 (v1 → 2A)

| 항목 | v1 | 2A |
|---|---|---|
| 걷기 지속 | 2~8초 | 4~10초 |
| 쉬기(앉기·두리번) 지속 | 3~6초 | 1.5~3초 |
| 잠들 확률 (쉬기 종료 시) | 25% | 8% |
| 잠 지속 | 15~40초 | 6~12초 |
| 걷기 속도 | 고양이 60 / 강아지 70 / 토끼 80 / 비버 40 | ×1.5 → 90 / 105 / 120 / 60 (`pet.json` `walk_speed`) |
| 창 모서리(Edge)에서 걷기 | 50% 폴짝 | 80% 폴짝 / 20% 뒤돌기 |

### 2.2 이동 방식

쉬기·애교가 끝나고 이동을 시작할 때 하나를 고른다 (방향은 50% 확률로 반전).

| 이동 | 확률 | 속도 | 지속 | Edge 도달 | Blocked / Wall 도달 |
|---|---|---|---|---|---|
| 걷기 `Walk` | 55% | `walk_speed` | 4~10초 | 80% Hop / 20% Turn | Turn |
| 뛰기 `Run` | 30% | ×2.5 | 2~5초 | 항상 멀리 점프 (vx ×1.8) | Turn |
| 구르기 `Roll` | 15% | ×2.0 | 2~4초 | 굴러 떨어짐 (속도 유지한 채 Fall) | Turn |

- 이동 종료 시: 30% Turn, 나머지는 쉬기/애교 선택.
- 좁은 조각(폭 < 몸 폭)·발밑 덮임·창 소멸 규칙은 v1과 동일.

### 2.3 쉬기와 애교

이동이 끝나면 다음 중 하나:

- **옆모습 쉬기** (70%): `Idle` 1.5~3초, 절반은 두리번(`look`). 종료 시 8% 잠.
- **앞모습 애교** (30%): 아래 중 균등 랜덤, 2~4초 유지 후 이동 재개.
  - `sit_front` 앉아서 바라보기, `wave` 손 흔들기, `tilt` 고개 갸웃(물음표), `belly` 배 보여주기, `stretch` 기지개, `heart` 하트 뿌뿌

애교 중에도 발밑 덮임·창 소멸 시 Fall, 창 이동 시 타고 가기는 동일.

### 2.4 클릭 반응

- 서 있을 때(이동·쉬기·애교) 짧은 클릭: 랜덤 반응 — 점프+하트(v1 Happy), `heart`, `wave`, `tilt` 중 균등.
  애교 반응은 2초 유지 후 쉬기로.
- 잠잘 때 클릭: 깨어나 쉬기 (v1 동일).
- 공중 클릭·드래그·던지기: v1 동일.

### 2.5 방향

- 옆모습 동작은 `facing`에 따라 좌우 반전.
- 앞모습 동작(`front: true`)은 반전하지 않는다.

## 3. 그림 체계

### 3.1 동작 목록 (`pet.json` 필수 15개)

| 구분 | 동작 | 방향 |
|---|---|---|
| 이동 | `walk`, `run`, `roll` | 옆 |
| 쉬기 | `idle`, `look`, `sleep` | 옆 |
| 공중 | `hop`, `fall`, `dragged`, `land` | 옆 |
| 애교 | `sit_front`, `wave`, `tilt`, `belly`, `stretch`, `heart` | 앞 (`"front": true`) |

`AnimSpec`에 `front: bool` (기본 false)과 `spin: f64` (기본 0, 초당 회전 각도 — `roll` 전용)를 추가한다.
`roll`은 공처럼 만 그림 1~2프레임을 쓰고, 웹뷰가 경과 시간 × `spin`만큼 회전시킨다
(방향은 `flip`에 따라 반대). `spin`은 구르기 속도와 몸 반지름에서 정한다: `spin = 구르기 속도 / 반지름 × 180/π`.

### 3.2 해상도

- 프레임 **128×128**, 화면 표시 128 논리 px (확대 없음 → 보간 일반 모드, `image-rendering: auto`).
- `frame_size: 128`. 웹뷰는 `DISPLAY / frame_size` 배율을 이미 쓰므로 그대로 동작한다.

### 3.3 스타일 — 말랑 카와이

- 머리·귀·몸·다리·꼬리를 도형으로 합친 뒤 **가우시안 블러 + 임계값으로 녹여** 한 덩어리 실루엣을 만든다.
- 실루엣을 확장해 **굵은 갈색빛 외곽선** (RGB 132,96,92, 약 3px).
- 무늬는 실루엣 안에만 칠한다. 큰 머리, 멀찍한 점 눈(하이라이트), 빗금 볼터치, 분홍 귀 안쪽, 손 흔들기 때 젤리 발바닥.
- 4× 슈퍼샘플링 후 128로 축소.
- 확정 시안: `design-preview` 브랜치 `design-preview/kawaii-all-*.png`.

동물별 특징:

| 동물 | 특징 |
|---|---|
| 고양이 | 사용자 고양이: 흰 바탕 + 치즈색 머리·귀·등·꼬리 줄무늬, 이마 흰 줄, 고양이 왼쪽 볼 치즈 점, 분홍 코 |
| 강아지 | 크림 + 갈색, 처진 진갈색 귀(경계선), 한쪽 눈가 점, 둥근 꼬리 |
| 토끼 | 흰색, 긴 귀(분홍 안쪽), 동그란 꼬리 — 귀 때문에 전체 배율 0.8 |
| 비버 | 갈색, 작은 동그란 귀, 밝은 주둥이·배, 앞니 두 개, 넓적한 진갈색 꼬리(빗금) |

### 3.4 그림 생성 도구

- `tools/draw_pets.py`: 시안 코드를 정리한 생성기. 실행하면 `ui/pets/{cat,dog,rabbit,beaver}/sheet.png` + `pet.json` 생성.
  - 종별 설정(색, 귀, 꼬리, 무늬, 얼굴)과 포즈 뼈대(동작별 프레임 함수)를 분리한다.
- `tools/gen_placeholder.py` 삭제.
- `tools/sprite_spec.py`: 동작 목록 15개, 기본 프레임 수·fps·loop·front·spin 정의 (Rust `REQUIRED_ANIMS`와 같은 순서).
- `tools/pack_sheet.py`: AI 그림 교체 경로 유지. 프레임 크기 128로 변경, `front`/`spin`을 매니페스트에 반영.
- `docs/sprites.md` 갱신 (128px, 15동작, 앞모습 규칙).

## 4. 크기 배율 구조 (2B 대비)

- 기준 크기 128 논리 px = teenager 배율 1.0.
- 게임 루프의 펫 크기를 `PET_LOGICAL_SIZE × stage_scale`로 계산하고, 펫 창 크기(`set_size`)와 `PetConfig.size`/`half_w`를 같은 값에서 만든다.
- 2A에서는 `stage_scale = 1.0` 고정. 웹뷰는 창 크기에 맞춰 스프라이트를 그린다 (CSS `width/height: 100%`, `background-size`를 창 크기 기준으로).

## 5. 화면 표시 (웹뷰)

- `front` 동작은 `flip` 무시.
- `roll`은 `transform: rotate()` 연속 회전 (`flip`이면 반대 방향).
- `heart` 동작 동안 작은 하트들이 위로 뽀뽀 떠오르는 연출, `tilt` 동안 물음표 말풍선.
- 클릭 하트(v1) 연출 유지.

## 6. 테스트

- **Rust (리눅스)**:
  - 이동 방식 선택 비율 (많은 시드에서 55/30/15 ±허용오차)
  - Edge 규칙: 걷기 80/20, 뛰기 항상 점프(vx 큼), 구르기 Fall
  - 애교 선택·유지 시간, 애교 중 발밑 덮임 → Fall
  - 클릭 반응 랜덤 4종, 잠 클릭 → 쉬기
  - `render()`: 앞모습 동작은 `flip=false`
  - **10분 시뮬레이션**: 이동(걷기+뛰기+구르기) 65~75%, 잠 ≤ 10%
  - 매니페스트 15동작 검증, `front`/`spin` 파싱
- **Python**: draw_pets가 4종 × 15동작을 생성, 모든 프레임이 128 칸 안(가장자리 1px 투명), 발이 바닥선 근처, pack_sheet 128 규격
- **시각 확인**: 4종 × 15동작 전체 시트를 `design-preview` 브랜치에 올려 사용자 확인 후 앱 빌드
- **수동 (Windows)**: README 체크리스트에 뛰기·구르기·애교·클릭 반응 항목 추가
