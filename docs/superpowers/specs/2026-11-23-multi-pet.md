# 🐾🐾🐾 펫 여러 마리 키우기 (2026-11-23 요청)

사용자: "한 사람이 펫 여러 마리 키우게 — 3마리쯤. 2단계까지 한 번에. 집에 와 메뉴도 캐릭터별로 + 전체 다 선택 가능하게.
같은 종류로도 최대 3마리. 하우스 / 숨기기 / 집중 모드는 다 한 번에 전체 적용."

## 정한 것

1. **최대 3마리** (`MAX_OWN_PETS = 3`). 같은 종류도 됨 (흐물이 셋도 됨). 처음 설치는 지금처럼 한 마리.
2. **펫마다 따로 자람**: 돌보기 상태 (포만감·성장 단계·경험치 등 `Care`)는 종류가 아니라 펫 하나하나 (고유 `uid`)에 붙음.
3. **트레이 메뉴**
   - 🐾 펫 추가 (종류 고르기) · 펫마다 종류 바꾸기 · 펫 보내 주기 (빼기 — 마지막 한 마리는 못 뺌, 확인 창)
   - 🏡 "집에 와" (친구에게 가 있는 내 펫 불러오기): 펫마다 하나 + "모두"
   - 친구에게 보내기도 펫마다 (지금 보내기 메뉴가 있는 자리마다 펫 고르기 — 하나뿐이면 지금과 같음)
   - 🎮 조작 모드: 어느 펫을 조종할지 고름 (기본 첫 펫)
   - 밥 주기: 자동 그릇은 배고픈 펫 모두가 먹으러 옴, 손으로 주기는 고른/가까운 펫
   - 🏠 하우스 · 🙈 숨기기/보이기 · 🎯 집중 모드: **전체에 한 번에** 적용 (모두 들어가고 모두 나옴)
4. **친구 화면**: 내 펫마다 따로 놀러 감 (한 번에 여럿이 가 있어도 됨). 친구 화면엔 펫마다 내 이름표. 친구가 "데려오기"는 지금처럼.
5. **집 식구끼리**: 친구 펫 손님과 노는 것과 똑같이 서로 놀음 (social 코디네이터가 이미 여러 펫을 다룸).

## 옛 설정·옛 버전과의 호환

- 새 필드 `pets: [{uid, species, care}]` (순서 = 메뉴 순서, 첫 펫 = 대표 — 창 라벨 `pet` 그대로).
- 읽을 때: `pets`가 없으면 옛 `pet` + `care[pet]`에서 한 마리를 만듦 (이사).
- 쓸 때: 옛 필드 `pet` / `care[첫 펫 종류]`도 첫 펫 것으로 계속 씀 — 옛 버전으로 되돌려도 첫 펫이 그대로.
- 친구 통신: 놀러 갈 때 이미 `Visit`에 종류·단계·visit_id가 실림. 같은 친구에게 내 펫 둘이 동시에 가는 것·펫별 "집에 와"가
  옛 친구 앱에서 깨지면 `PROTOCOL_VERSION` 7로 올리고 `peer_version`으로 막음 (옛 친구에겐 한 번에 한 마리만).

## 고칠 곳 (앱 — `src-tauri/src`)

- `slots.rs`: `OWN` (=0) 하나를 가정한 곳 → 내 펫 슬롯 여럿 (`Role::Own(uid)`, 라벨 `pet`, `pet-2`, `pet-3`).
  `is_own()` 쓰는 곳 점검. 손님 슬롯은 그 뒤.
- `game_loop.rs` (`slots[OWN]`/`own.` 200곳쯤): 펫마다 해야 하는 것 (돌보기·떠남/돌아옴·하우스 들어감·말풍선·먹이 요청·조작)과
  화면에 하나인 것 (세계·dpi·커서 기준 — 첫 슬롯 것을 써도 됨)을 나눔.
- `tray.rs`: 메뉴 (위 3번). 상태 표시 (`set_own_busy`, away/housed atomics `AppState`)는 펫마다 또는 "모두".
- `network.rs`: 내 펫이 친구에게 가 있음·돌아옴·답장·`pair_lift`·데려오기를 펫(uid/visit_id)별로.
- `presence.rs`·`house.rs`·`vehicles.rs`·`sleigh.rs`·`objects.rs`·`prop.rs`: `OWN` 가정 점검.
- `screenpet-core/src/config.rs`: `pets` 필드·이사·옛 필드 쓰기 + 테스트.
