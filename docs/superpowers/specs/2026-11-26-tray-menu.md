# 트레이 메뉴 전체 개편 (2026-11-26)

사용자: "트레이 메뉴가 너무 어려워졌어 … 메뉴 뎁스를 줄여 줘 … 선택한 펫 누르고 다시 트레이 메뉴 꺼지고, 다시 켜서 바꾸는 것도 이상해 …
메뉴 전체적으로 편리하게 개편해 봐", "여러 펫 그것만 수정하지 말고 전반적으로 다 개편해. 편리하게.", "집중 친구 → 🍅 뽀모도로".

## 원칙

- 자주 쓰는 것은 맨 위 (밥, 하우스, 집에 와, 조작, 숨기기, 뽀모도로). 나머지는 묶음: 🐾 펫 · 🎮 놀기 (혼자 + 👫 친구) · ⚙️ 설정 · ℹ️ 도움말·건의.
- 흔한 것은 깊이 둘까지 (▸ 두 번). 글자는 짧게, 이모지는 하나씩. 같은 항목이 두 군데 있지 않음.
- 지금 할 수 없는 것은 숨기거나 흐리게 (집에 와는 놀러 간 펫이 있을 때만, 꽉 차면 펫 추가 흐림, 놀러 가 있으면 종류 바꾸기 흐림 …).
- 개발자 전용 (📊 펫 통계)은 개발자 컴퓨터에만.
- "고른 펫 ▸에서 고르고 → 메뉴 닫힘 → 다시 열어 다루기"는 없음: 펫마다 맨 위 하위 메뉴, 조작은 펫마다 체크.
- 메뉴는 모양이 바뀔 때만 (펫 추가·보내 주기·종류 흐물이↔다른 동물·놀러 감·연결된 친구) 다시 만들고, 아니면 글자·체크만 바꿈.
  메인 스레드 메뉴 처리기는 입력만 보냄, 메뉴 바꾸기는 잠금 밖에서 (게임 루프 스레드).

## 옮긴 것

- 🎮 조작: 🎮 놀기 ▸ → 맨 위 (여럿이면 펫마다 체크).
- 🕐 최근 한 시간: 🐾 내 펫 ▸ → 🎮 놀기 ▸.
- 👫 친구랑 놀기 ▸ 와 🎮 놀기 ▸ 를 하나로: 🎮 놀기 ▸ 혼자 놀기 아래 구분선 + 👫 친구 묶음 (친구마다 ▸ 가 깊이 둘에 오도록 친구 하위 메뉴를 따로 두지 않음).
- 🎲 사다리타기 ▸·🗑️ 쓰레기 10개 던지기 ▸: 🎮 놀기 ▸ 의 친구 묶음. 내 이름·인터넷 연결·코드는 👫 내 이름·친구 코드 ▸.
- 📍 날씨 지역 ▸: ⚙️ 설정 ▸ 🌦️ 날씨 종류 ▸ 안 → ⚙️ 설정 ▸ 바로 아래.
- 도움말·건의하기·건의함·펫 통계·업데이트: 맨 위 → ℹ️ 도움말·건의 ▸.
- 옛 👫 친구랑 놀기 ▸ 놀러 보내기 ▸ (친구 목록): 펫 하위 메뉴의 놀러 보내기 ▸ 로 (친구 하위 메뉴의 놀러 보내기는 그대로, 여럿이면 펫마다 항목).
- 🔄 업데이트 → ⬆️ 업데이트 (🔄은 새로고침).
- ⏱️ 집중 친구 → 🍅 뽀모도로.
