# 개발된 파일 계층 구조

> **요약.** 저장소는 Cargo 워크스페이스(크레이트 5개 + Tauri 앱)와 웹뷰 UI, 그림 생성 도구, 배포 스크립트로 나뉨.
> 규칙은 OS·창을 모르는 `screenpet-core`에, 네트워크는 `screenpet-net`에, 서버는 `screenpet-relay`에, 양쪽이 같이 지키는 와이어 약속은 `screenpet-proto`·`screenpet-crypto`에 있음.
> `src-tauri`는 이 크레이트들을 창·트레이·웹뷰에 잇는 얇은 층이고, `ui/`의 그림(PNG)은 거의 모두 `tools/draw_*.py`가 만든 생성물임.
>
> 기준 커밋: `ba6634b`

### 2.2 패턴: `brain_<기능>.rs` + `brain_<기능>_tests.rs`

- `brain.rs`가 `Pet`을 갖고, 기능마다 `brain_<기능>.rs`가 **자식 모듈**로 붙어 `Pet`의 비공개 필드를 씀 (각 파일 첫 줄 "brain.rs의 자식 모듈").
- 숫자·순수 계산은 짝 파일에 둠: `brain_juggle.rs` ↔ `juggle.rs`, `brain_poop.rs` ↔ `poop.rs`, `brain_taskbar.rs` ↔ `taskbar.rs`, `brain_knock/stash/quake/train.rs` ↔ `play.rs`, `brain_fly.rs` ↔ `flight.rs`, `brain_hop.rs` ↔ `hop.rs`.
- 시험은 `brain_<기능>_tests.rs` (같은 이름 + `_tests`). 기능 하나 찾을 때 이 세 파일을 같이 보면 됨.
- 같은 패턴: `social.rs` ↔ `social_play.rs`, `social_tower.rs`, `social_*_tests.rs`.

| `ui/house/*` | 생성 | `python tools/draw_house.py` (`xmas`만도 가능) |
| `ui/house_pixel/*`, `*_pixel/` 세계 그림 | 생성 | `python tools/draw_pixel_world.py` (칸 표는 `pixel_world_icons.py`) |
| `ui/objects/*.png` | 생성 | `python tools/draw_objects.py` (`--shapes`는 `tumble.rs`에 붙일 표 출력) |
| `ui/effects/{bowl_food,bowl_water,cookie}.png` | 생성 | `python tools/draw_props.py` |
| `ui/gifts/*.png` | 생성 | `python tools/draw_gifts.py` |
| `ui/sleigh/*.png` | 생성 | `python tools/draw_sleigh.py` |
| `tools/icon.png` | 생성 | `python tools/make_icon.py` |
| `tools/round_art_hashes.json` | 생성 (검사 기준) | `python tools/draw_pixel_world.py --round-digest`. 동글 그림(`effects, gifts, objects, house, pets`) sha256 앞 16자. 픽셀 작업이 동글 그림을 바꾸지 않았는지 `test_draw_pixel_world.py`가 확인 |
| `tools/preview/*.png` | 생성, **git 제외** | 각 `draw_*`가 같이 씀, `preview_nightcap.py`, `preview_scarf.py` |

## 8. 시험 위치와 돌리는 법

| 대상 | 위치 | 명령 |
|---|---|---|
| core | `src/*_tests.rs`, 각 파일 `mod tests`, `tests/update_sign.rs` | `cargo test -p screenpet-core` |
| net | `src/*` `mod tests`, `tests/{net,relay,ladder}.rs` | `cargo test -p screenpet-net` |
| crypto | `src/lib.rs` `mod tests` | `cargo test -p screenpet-crypto` |
| proto | `tests/golden.rs`, `weather.rs` `mod tests` | `cargo test -p screenpet-proto` |
| log | `src/lib.rs` `mod tests` (형식·시각·가리기) | `cargo test -p screenpet-log` |
| relay | `src/hub/tests.rs`, 각 파일 `mod tests`, `tests/{relay,downloads}.rs` | `cargo test -p screenpet-relay` |
| 실제 릴레이 연기 시험 | `screenpet-net/tests/relay.rs` (`#[ignore]`) | `SCREENPET_LIVE_RELAY=wss://pet.danni.day/ws cargo test -p screenpet-net --test relay -- --ignored live_relay_smoke` |
| OS 코드 컴파일 | – | `cargo check -p screenpet-core --target x86_64-pc-windows-gnu` / `aarch64-apple-darwin` |
| Python 도구·UI·정책 | `tools/test_*.py` | `cd tools && python -m pytest -q` (Python 3.12, `pip install --require-hashes --only-binary :all: -r tools/requirements.txt`) |
