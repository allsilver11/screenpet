## 🕷️ 거미인간, 🌀 태풍, 🌦️ 날씨 직접 고르기

- **🕷️ 새 펫 거미인간:** 빨강·파랑 슈트의 동글 거미예요. 화면·창 구석에 거미집을 치고 (친구 집에 놀러 가면 더 자주!), 거미줄 그네로 휙 날아다니고, 높이서 떨어지면 히어로 착지! 팔을 쭉 뻗어 거미줄을 쏴서 쓰레기나 다른 펫을 끌어와 던져요. 거미집은 🧹 다 치우기나 1시간마다 저절로 지워져요.
- **🌀 태풍:** 여름(7~9월)에 가끔 태풍이 와요. 강풍에 펫과 물건이 날아가고, 회오리에 빨려 올라가 빙글빙글 돌다가 친구 모니터까지 날아가요! 집 안에 있는 펫은 안전해요.
- **🌨️ 함박눈:** 한겨울(12~2월) 어떤 날엔 크고 몽실한 눈송이가 펑펑 쏟아져요! 보통 눈보다 훨씬 빨리, 훨씬 높이 쌓여서 눈사람·눈싸움하기 딱 좋아요. 날씨 종류에서 직접 골라도 되고, 실제로 눈이 많이 오는 날에도 와요.
- **🌦️ 날씨 직접 고르기:** ⚙️ 설정 ▸ 🌦️ 날씨 종류에서 ❄️ 눈 / 🌨️ 함박눈 / 🌧️ 비 / 🍂 낙엽 / 🌸 꽃잎 / 🌿 푸른 잎 / 🌀 태풍을 골라 계절과 상관없이 즐길 수 있어요.
- **🧹 빗자루로 뭐든 쓱쓱:** 이제 똥뿐 아니라 쓰레기·앱 아이콘·눈덩이·거대한 돌까지 빗자루로 밀려요. 친구가 연결된 화면 끝까지 쭉 밀면 친구 화면으로 슝 날아가요!
- **🌿 여름 푸른 잎:** 여름엔 싱싱한 초록 잎이 팔랑팔랑 날리고 쌓여요. 🌸 꽃잎도 낙엽처럼 쌓이고 펫들이 뛰어들어 놀아요.
- **📍 미국 도시:** 실제 날씨 지역에 뉴저지·펜실베이니아·뉴욕·샌프란시스코가 생겼어요.
- **🏠 놀러 간 펫 길 잃음 고침:** 친구 앱이 다시 켜지면 놀러 가 있던 펫이 바로 집에 돌아와요 (친구도 0.6.8이어야 해요).
- **🐾 데려오기 답:** 친구가 바빠서 못 보내 줄 때 "busy~" 말풍선이 보이게 했고, 친구 펫이 이미 와 있으면 메뉴에 "이미 와 있어요"라고 나와요.
