## 🛠️ 작은 손질

- **⌨️ 타자 응원:** 흐물이가 이제 작은 키보드 앞에 앉아 같이 타자를 쳐요! 내가 키를 누를 때마다 손을 번갈아 톡톡, 멈추면 손도 쉬어요. 가끔 만세도 하고 "Type type!", "So fast!" 하고 응원해요 (아주 빠르면 "🔥 Speedy!").
- **🔄 업데이트:** 서버에 아직 올라온 업데이트가 없을 때 "받지 못했어요" 대신 "최신 버전이에요"라고 보여요.
- **🪟 Windows 설치 파일:** 이제 `.exe` 하나만 나와요 (헷갈리던 `.msi`는 뺐어요).
- **🔄 새 버전 알림:** 새 버전이 나왔는지 6시간 대신 2시간마다 확인해요.
