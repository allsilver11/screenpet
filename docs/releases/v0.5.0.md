## 🎲 친구들과 사다리타기, 그리고 큰 점검

### 🎲 사다리타기 (@mxxxxwoo 님, 고마워요! 🎉)
[@mxxxxwoo](https://github.com/mxxxxwoo) 님이 [PR #1](https://github.com/allsilver11/screenpet/pull/1)로 만들어 주셨어요.
- `친구랑 놀기 ▸ 🎲 사다리타기`로 친구를 초대해요. 방장 포함 최대 10명이에요.
- 모두의 화면에 같은 사다리가 뜨고, 각자의 펫이 아기 모습으로 내려가요.
- 내 진짜 펫도 결과에 만세하거나 갸웃해요.
- 결과 표, `결과 복사`, `지난 사다리 결과`가 있어요.
- 집중 중이거나 하우스 안이면 초대를 자동으로 거절해요. 메뉴로 초대를 끌 수도 있어요.

### 새로워진 것
- **메뉴 정리:** 트레이 메뉴를 `내 펫`, `친구랑 놀기`, `놀기`, `설정`으로 묶었어요.
- **친구 삭제:** 친구가 나를 지우면, 다시 연결될 때 나에게서도 지워져요.
- **설치 파일 축소:** 안 쓰는 그림을 지웠어요.
- **🗑️ 물건 10개 던지기:** 친구 메뉴에서 누르면 여러 가지 쓰레기 10개를 친구 화면으로 던져요. 똥은 빠지고, 친구가 집중 중이거나 하우스 안이면 되돌아와요. 동료의 아이디어예요. 고마워요! 🎉
- **똥 모양:** 소프트아이스크림처럼 둘둘 쌓인 모양으로 바꿨어요. 토끼는 그대로 알갱이예요.

### 안전
코드 전체를 처음부터 끝까지 다시 읽어 점검했어요.
- **이름:** 이름을 정하지 않았다면 컴퓨터 로그인 이름 대신 "친구"로 보여요. 이름을 정해 두면 그대로예요.
- **친구 신청:** 낯선 사람의 신청 창이 작업을 방해하지 않아요.
- **메시지 폭주:** 친구가 메시지를 쏟아도 앱이 멈추지 않게 제한했어요.
- **보안 부품:** 인터넷 연결 암호화 부품을 검증된 것으로 바꿨어요.
- **웹 보안 정책:** 앱 화면의 방어막을 켰어요.
- **서버:** 인터넷 친구를 이어 주는 서버도 공격에 대비해 강화했어요.

### 고친 것
- **인터넷 연결:** Windows에서 인터넷이 느리면 친구 서버에 접속하지 못하던 문제
- **친구 목록:** 설정 파일을 잠깐 못 읽으면 친구 목록이 지워질 수 있던 문제
- **Alt+F4:** 펫 창이 닫혀 돌아오지 않던 문제
- **편지:** 보내지 못한 편지가 조용히 사라지던 문제
- **모니터:** 위아래로 쌓은 모니터에서 펫이 창에 못 올라가던 문제
- **Enter 키:** `닫기`를 선택하고 Enter를 누르면 제출되던 문제
- **안 돌아오는 펫:** 친구가 답이 없어도 32분 뒤에는 돌아와요.
- **그림:** 배고픈 개구리의 팔, 픽셀 눈사람 모자 등
