## 친구 펫과 더 많이 놀기

- **던지기:** 펫을 세게 던지면 친구 화면으로 날아가요.
- **보내기:** 메뉴에서 친구를 골라 펫을 보내요. 친구에게 부탁해서 친구 펫을 데려올 수도 있어요.
- **이어 보내기:** 놀러 온 친구 펫을 다른 친구에게 보내요.
- **친구 펫 놀아 주기:** 애교를 부리거나 마우스에서 도망쳐요.
- **펫끼리:** 서로 인사하고 술래잡기를 해요.
- **이름:** 친구에게 보일 이름을 정하고, 친구에게 별명을 붙여요.
- **토끼:** 절반은 깡충깡충 뛰어다녀요.
- **꿀벌:** 더 둥글고 활기차게 날아요.

v0.3.3의 변경 사항을 포함해요.
